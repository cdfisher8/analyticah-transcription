Word exports a Word-compatible .doc file. PDF uses your browser's Print → Save as PDF. Auto-save stores text in this browser's local storage, not Google Drive. Clearing browser data or opening the file in a different browser can make saved drafts unavailable.

Best in current Microsoft Edge or Chrome. Allow microphone permission when asked. Browser speech recognition may use an online service.
